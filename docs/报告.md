
# Spring Boot + Vue3 AI聊天系统开发教程

## 📚 一、项目概述

### 1.1 项目背景

这是一个**前后端分离的AI对话系统**，实现了：
- 👤 **用户管理**：注册、登录、用户信息管理
- 🔐 **安全认证**：基于JWT的无状态身份验证
- 💬 **AI对话**：集成DeepSeek API的智能问答
- 📝 **对话历史**：多会话管理和历史记录

**适合人群**：有Java和JavaScript基础，想学习企业级前后端开发的同学

### 3.2 前后端分离架构详解

#### 为什么采用前后端分离？

**传统架构（JSP/Thymeleaf）**：
```
浏览器 → Tomcat → Controller → 渲染HTML → 返回完整页面
❌ 前后端耦合，难以并行开发
❌ 页面刷新体验差
❌ 移动端适配困难
```

**前后端分离架构**：
```
浏览器 → Nginx → Vue SPA (仅首次加载HTML)
         ↓
浏览器 ↔ API接口 ↔ Spring Boot (返回JSON数据)
✅ 前后端独立开发部署
✅ SPA单页应用流畅
✅ 同一套API支持Web/App
```

### 3.4 数据流转过程（以登录为例）

```
用户操作：输入用户名密码 → 点击登录按钮
    ↓
【前端】Login.vue
    ↓ 调用API
【前端】api/auth.js → login({username, password})
    ↓ Axios拦截器添加请求头
【前端】utils/axios.js → POST /api/auth/login
    ↓
━━━━━━━━━━━━━━━━ HTTP请求 ━━━━━━━━━━━━━━━━
    ↓
【后端】JwtAuthenticationFilter → 登录接口在白名单，放行
    ↓
【后端】AuthController.login() → 接收请求
    ↓ 调用服务
【后端】UserService.login()
    ├─ UserMapper.findByUsername() → 查询数据库
    ├─ BCryptPasswordEncoder.matches() → 验证密码
    └─ JwtUtil.generateToken() → 生成Token
    ↓ 返回
【后端】ApiResponse<TokenDTO> → 包装响应
    ↓
━━━━━━━━━━━━━━━━ HTTP响应 ━━━━━━━━━━━━━━━━
    ↓
【前端】Axios响应拦截器 → 检查状态码
    ↓ 成功
【前端】Login.vue
    ├─ localStorage.setItem('token', response.token)
    ├─ userStore.setUser(response.user)
    └─ router.push('/chat') → 跳转聊天页
```

**关键点解析**：

1. **为什么前端存储Token到localStorage？**
   - ✅ 刷新页面不丢失登录状态
   - ✅ 跨Tab页面共享
   - ⚠️ 注意：XSS攻击风险（需前端做输入过滤）

2. **为什么用BCrypt加密密码？**
   - ✅ 自动加盐（salt），同一密码每次加密结果不同
   - ✅ 慢哈希算法，防止暴力破解
   - ❌ 不可逆，只能验证不能解密

3. **为什么JWT无状态？**
   - ✅ 服务端不存储Session，易于水平扩展
   - ✅ Token包含用户信息，减少数据库查询
   - ⚠️ 无法主动失效（可配合Redis黑名单）
```

## 🔧 四、核心功能模块详解

### 4.1 JWT认证机制实现

#### 💡 JWT工作原理

```
登录流程：
用户登录 → 验证密码 → 生成JWT → 返回客户端 → 存储localStorage

访问受保护接口：
客户端请求 → 携带JWT → 过滤器验证 → 解析用户信息 → 放行/拒绝
```

#### 📝 核心代码详解

**1. JwtUtil - Token生成与解析**

```java
@Component
public class JwtUtil {
    private final SecretKey secretKey;
    private final long expirationMinutes;

    // 构造函数：从配置文件读取密钥和有效期
    public JwtUtil(@Value("${jwt.secret}") String secret,
                   @Value("${jwt.expiration-minutes}") long expirationMinutes) {
        // ⚠️ 重要：密钥长度必须>=32字节，用于HS256算法
        this.secretKey = Keys.hmacShaKeyFor(secret.getBytes(StandardCharsets.UTF_8));
        this.expirationMinutes = expirationMinutes;
    }

    // 生成Token
    public String generateToken(Long userId, String username) {
        Instant now = Instant.now();
        return Jwts.builder()
                .subject(username)                    // 主体：用户名
                .issuedAt(Date.from(now))             // 签发时间
                .expiration(Date.from(now.plus(       // 过期时间
                    expirationMinutes, ChronoUnit.MINUTES)))
                .claims(Map.of("userId", userId))     // 自定义声明
                .signWith(secretKey)                  // 签名算法：HS256
                .compact();                           // 生成紧凑格式
    }

    // 解析Token
    public Claims parseClaims(String token) {
        return Jwts.parser()
                .verifyWith(secretKey)                // 验证签名
                .build()
                .parseSignedClaims(token)             // 解析
                .getPayload();                        // 获取负载
    }
}
```

**关键点解析**：
- **为什么用HS256而不是RS256？**
  - HS256：对称加密，速度快，适合单体应用
  - RS256：非对称加密，更安全，适合微服务（公钥验证）

- **Claims包含什么？**
  ```json
  {
    "sub": "admin",           // subject 用户名
    "iat": 1705000000,        // issued at 签发时间
    "exp": 1705007200,        // expiration 过期时间
    "userId": 1               // 自定义字段
  }
  ```

**2. JwtAuthenticationFilter - 请求拦截验证**

```java
@Component
@RequiredArgsConstructor
public class JwtAuthenticationFilter extends OncePerRequestFilter {

    private final JwtUtil jwtUtil;
    
    // 白名单：无需验证的接口
    private final List<String> whitelist = List.of(
            "/api/auth/login",     // 登录接口
            "/api/auth/register",  // 注册接口
            "/actuator/**"         // 监控端点（生产需关闭）
    );

    // 判断是否需要过滤
    @Override
    protected boolean shouldNotFilter(HttpServletRequest request) {
        String path = request.getRequestURI();
        // OPTIONS请求（CORS预检）直接放行
        if ("OPTIONS".equalsIgnoreCase(request.getMethod())) {
            return true;
        }
        // 匹配白名单
        return whitelist.stream().anyMatch(pattern -> 
            pathMatcher.match(pattern, path));
    }

    // 核心过滤逻辑
    @Override
    protected void doFilterInternal(HttpServletRequest request, 
                                    HttpServletResponse response, 
                                    FilterChain filterChain)
            throws ServletException, IOException {
        // 1. 从Header提取Token
        String auth = request.getHeader(HttpHeaders.AUTHORIZATION);
        if (auth == null || !auth.startsWith("Bearer ")) {
            unauthorized(response, "Missing token");
            return;
        }
        
        String token = auth.substring(7);  // 去除"Bearer "前缀
        
        try {
            // 2. 验证并解析Token
            Claims claims = jwtUtil.parseClaims(token);
            
            // 3. 将用户信息存入Request，供Controller使用
            request.setAttribute("userId", 
                Long.valueOf(claims.get("userId").toString()));
            request.setAttribute("username", claims.getSubject());
            
            // 4. 放行请求
            filterChain.doFilter(request, response);
        } catch (Exception ex) {
            // Token过期或无效
            unauthorized(response, "Invalid or expired token");
        }
    }

    // 返回401未授权响应
    private void unauthorized(HttpServletResponse response, String message) 
            throws IOException {
        response.setStatus(HttpServletResponse.SC_UNAUTHORIZED);
        response.setContentType(MediaType.APPLICATION_JSON_VALUE);
        String body = String.format(
            "{\"code\":401,\"message\":\"%s\",\"data\":null}", message);
        response.getOutputStream().write(
            body.getBytes(StandardCharsets.UTF_8));
    }
}
```

**工作流程图**：
```
HTTP请求 → Filter拦截
    │
    ├─ 白名单？──是→ 放行
    │       │
    │       否
    │       ↓
    ├─ 有Token？──否→ 返回401
    │       │
    │       是
    │       ↓
    ├─ Token有效？──否→ 返回401
    │       │
    │       是

#### 💼 Service层业务逻辑

```java
@Service
@RequiredArgsConstructor
public class UserServiceImpl implements UserService {

    private final UserMapper userMapper;
    private final JwtUtil jwtUtil;
    // BCrypt加密器，自动加盐
    private final PasswordEncoder passwordEncoder = 
        new BCryptPasswordEncoder();

    // 用户注册
    @Override
    public User register(RegisterRequest request) {
        // 1. 检查用户名是否已存在
        if (userMapper.findByUsername(request.getUsername()) != null) {
            throw new ApiException(400, "用户名已存在");
        }
        
        // 2. 创建用户实体
        User user = new User();
        user.setUsername(request.getUsername());
        // 3. BCrypt加密密码（自动加盐，每次结果不同）
        user.setPassword(passwordEncoder.encode(request.getPassword()));
        user.setEmail(request.getEmail());
        user.setNickname(request.getNickname());
        user.setStatus(1);
        
        // 4. 插入数据库
        userMapper.insert(user);
        
        // 5. 返回时隐藏密码
        user.setPassword(null);
        return user;
    }

    // 用户登录
    @Override
    public Map<String, Object> login(AuthRequest request) {
        // 1. 根据用户名查询
        User user = userMapper.findByUsername(request.getUsername());
        if (user == null) {
            throw new ApiException(401, "用户名或密码错误");
        }
        
        // 2. 验证密码（BCrypt自动处理盐值）
        if (!passwordEncoder.matches(request.getPassword(), user.getPassword())) {
            throw new ApiException(401, "用户名或密码错误");
        }
        
        // 3. 检查账号状态
        if (user.getStatus() == 0) {
            throw new ApiException(403, "账号已被禁用");
        }
        
        // 4. 生成JWT Token
        String token = jwtUtil.generateToken(user.getId(), user.getUsername());
        
        // 5. 返回Token和用户信息
        user.setPassword(null);  // 隐藏密码
        return Map.of(
            "token", token,
            "user", user
        );
    }
}
```

**为什么用WebClient而不是RestTemplate？**
- ✅ WebClient：非阻塞，支持响应式编程（Reactive）
- ✅ 适合调用慢速外部API（AI响应时间长）

**2. 调用AI API**

```java
@Service
@RequiredArgsConstructor
public class ChatServiceImpl implements ChatService {

    private final WebClient deepSeekClient;
    private final MessageMapper messageMapper;

    @Override
    public Message sendMessage(Long userId, Long conversationId, 
                               ChatMessageRequest request) {
        // 1. 保存用户消息
        Message userMsg = new Message();
        userMsg.setConversationId(conversationId);
        userMsg.setRole("user");
        userMsg.setContent(request.getContent());
        messageMapper.insert(userMsg);

        // 2. 调用DeepSeek API
        String aiContent = callDeepSeek(request.getContent());

        // 3. 保存AI回复
        Message aiMsg = new Message();
        aiMsg.setConversationId(conversationId);
        aiMsg.setRole("assistant");
        aiMsg.setContent(aiContent);
        messageMapper.insert(aiMsg);
        
        return aiMsg;
    }

    private String callDeepSeek(String prompt) {
        try {
            // 构建请求体
            Map<String, Object> requestBody = Map.of(
                "model", "deepseek-chat",           // 模型名称
                "temperature", 0.7,                 // 创造性（0-2）
                "messages", List.of(Map.of(
                    "role", "user",
                    "content", prompt
                ))
            );

            // 发送POST请求
            Map<String, Object> response = deepSeekClient.post()
                    .uri("/v1/chat/completions")
                    .bodyValue(requestBody)
                    .retrieve()
                    .bodyToMono(Map.class)          // 异步转同步
                    .block();                       // 阻塞等待结果

            // 解析响应
            List<?> choices = (List<?>) response.get("choices");
            Map<?, ?> choice = (Map<?, ?>) choices.get(0);
            Map<?, ?> message = (Map<?, ?>) choice.get("message");
            return (String) message.get("content");
            
        } catch (Exception ex) {
            throw new ApiException(502, "AI调用失败: " + ex.getMessage());
        }
    }
}

```

├─ Java基础：集合、IO、多线程

├─ Spring Boot：自动配置、Starter
├─ MyBatis：动态SQL、缓存

└─ 数据库设计：索引、事务、优化

实战阶段（1-2周）
├─ 本项目开发
